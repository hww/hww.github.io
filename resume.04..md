### ПРОЕКТ: Программно-аппаратный комплекс игрового автомата (с нуля)

(1) Frontend: разработка игрового ПО, архитектура и рантайм

* Детерминированное runtime-ядро игровой логики: иерархическая система управления процессами, архитектура ECS и Data-Driven (или Data-Oriented)*, а также кастомный Task Manager для жесткого контроля игрового цикла.
* Ключевые игровые подсистемы: модули динамической локализации, отказоустойчивая система сохранения и загрузки (Save/Load), а также подсистема аналитики.
* Кроссплатформенная виртуальная машина CARBON: изолированная среда для исполнения низкоуровневого кода, обеспечивающая аппаратную абстракцию игровой логики от целевой платформы.
* Высокопроизводительный интерпретатор LISP (SOOT): инструмент для кросс-компиляции, метапрограммирования и гибкого управления игровыми ресурсами.
* Сетевая подсистема: коммуникационный слой для высокопроизводительного взаимодействия клиента с сервером и распределенными устройствами сбора данных и управления.
*Многопроходный кросс-компилятор для 8-битных архитектур: решение с гибкой системой типов, автоматизирующее расчет смещений в памяти и генерацию кода для микроконтроллеров.


(2) Backend: сетевой стек и инфраструктура

* Серверная часть: легковесный кастомный протокол обмена данными с последующим сохранением в базу данных, UDP-сервер для связи с игровым клиентом в реальном времени, а также HTTP-сервер для удаленного мониторинга.

(3) Аппаратная интеграция и прототипирование:

* Контроллеры сбора данных и управления: разработка нескольких аппаратных решений в форм-факторе 4-слойных печатных плат и комплекта встроенного ПО (Firmware) на C++ (bare-metal / Zephyr RTOS) под микроконтроллеры Nordic и ESP32 для обработки сигналов с периферии автомата.


### ПРОЕКТ:  Носимая R&D-система оптического контроля и 3D-визуализации телеметрии (PPG)

* Сетевой стек реального времени: UDP-протокол для высокоскоростной передачи телеметрии и показателей пульса на сервер с целью последующей графической визуализации.
* ВВстроенное ПО (C++): Firmware для микроконтроллеров ESP32, обеспечивающее оцифровку, фильтрацию и первичную математическую обработку сигналов с PPG-датчика в реальном времени.
* Аналоговый фронтенд (AFE): проектирование и трассировка печатных плат в Altium Designer, включая анализ целостности сигналов и питания (SI/PI) для минимизации шумов в измерительном тракте.
