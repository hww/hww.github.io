# Projects & Engineering History

My engineering work spans game runtime architecture, programming languages, performance engineering, embedded systems, FPGA design, and commercial hardware/software products.

This page organizes selected projects by technical area. For the complete chronological history, see the [main portfolio](/).

## Game Engines & Runtime Architecture

- **[Dynamic Component System (DCS)](https://github.com/hww/dcs)** — data-oriented component architecture for Unity, with dense pools, handles, and an event system.
- **[Gamebryo with GambitC Integration](/projects/gamebryo/)** — embedded Scheme scripting in a C++ game engine.
- **[SyberEngine 3D Development Platform](https://hww.github.io/articles/2003/syber_engine/index)** — component-based engine architecture, bytecode VM, scripting language, and development tools.
- **[Unity MVC Framework](https://github.com/hww/unity_mvc)** — lightweight Model–View–Controller architecture for Unity.
- **[SOOT — Scriptable Object-Oriented Toolkit](https://github.com/hww/soot)** — embeddable Lisp interpreter and automation toolkit.

## Programming Languages & Compilers

- **[Open GOAL Type System — Common Lisp](https://github.com/hww/open-goal-type-system-cl)** — parser, validation, and type analysis.
- **[Open GOAL Type System — Racket](https://github.com/hww/open-goal-type-system-for-racket)** — an alternative functional implementation.
- **[Lisp-Based Development Ecosystem](/projects/lisp/index)** — embedded language tooling for resource-constrained platforms.

## Unity Tools, Graphics & Performance

- **[XiGameTool](https://github.com/hww/XiGameTool)** — asset data extraction, transformation, and serialization tools.
- **[XiDebugDraw](https://github.com/hww/XiDebugDraw)** — runtime 3D debugging and visualization.
- **[XiKeyboard](https://github.com/hww/XiKeyboard)** — Emacs-style keyboard bindings for the Unity Editor.
- **[XiDebugMenu](https://github.com/hww/XiDebugMenu)** — in-game debugging interface.
- **[XiSound](https://github.com/hww/XiSound)** — lightweight audio system.
- **[3D Ray Tracer](https://github.com/hww/RayTracer)** — software ray tracing and graphics mathematics.
- **[Koch Fractals](https://github.com/hww/koch_fractals)** and **[Noise Flow Field](https://github.com/hww/noise_flow_field)** — procedural graphics experiments.
