# About Me

## Valeriya Pudova (hww)

**Systems Architect · R&D Infrastructure Engineer · Low-Level Specialist**

I work across hardware development, low-level execution layers, and high-performance software environments.

My engineering experience spans hardware prototyping, FPGA/HDL development, microcontrollers, embedded interpreters, custom compilers, and digital signal processing for real-time audio.

My software architecture work focuses on game engines and runtime systems: deterministic virtual machines, domain-specific languages (DSLs), embedded Lisp/Scheme runtimes, data-oriented design, memory optimization, and reverse engineering of complex engine pipelines.

I also work with hardware-software systems from electrical design and PCB layout through firmware, mechanical fabrication, and deployment.

## Core Areas of Expertise

- **Runtime and engine architecture:** deterministic simulation, task scheduling, state machines, scripting runtimes, and game-loop design.
- **Performance engineering:** memory layout, low-allocation and Zero-GC techniques, data-oriented design, and profiling.
- **Programming languages:** interpreters, virtual machines, AST parsing, type analysis, and custom DSLs.
- **Embedded and hardware systems:** microcontrollers, firmware, FPGA/HDL, PCB design, instrumentation, and hardware-software integration.
- **Graphics, DSP, and simulation:** rendering mathematics, ray tracing, real-time audio, and signal processing.
